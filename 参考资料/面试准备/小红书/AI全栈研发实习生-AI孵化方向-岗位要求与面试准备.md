# 小红书 AI 全栈研发实习生-AI 孵化方向

## 岗位信息

- 岗位名称：AI 全栈研发实习生-AI 孵化方向
- 职位类型：客户端开发
- 工作地点：上海市
- 目标方向：AI 创新产品孵化、全栈研发、AI Agent 应用落地

## 工作职责

1. 参与 AI 创新方向的产品孵化，从 idea brainstorm 到 MVP 上线全链路 owner。
2. 独立完成原型开发：前端、后端、模型调用、部署等。
3. 调研、设计并落地 AI Agent 相关能力，包括规划、记忆、工具使用、Multi-Agent 协作等。
4. 跟进海内外 AI 产品趋势，快速复现并迭代验证创新点。
5. 与产品、设计、算法同学高频协作，用最短链路把想法推向用户。

## 任职资格

1. 计算机、软件、人工智能等相关专业在校生，本科及以上。
2. 可保证每周 4 天以上、连续 3 个月以上实习。
3. 全栈开发能力优先，熟悉至少一套现代技术栈，例如 React/Next.js + Node/Python + 云部署，能独立交付完整产品。
4. 熟悉 LLM API 调用、Prompt Engineering、RAG 等 AI 应用基础能力。
5. 熟练使用 Claude、ChatGPT、Cursor、Claude Code、Codex 等 AI 工具，有自己的 workflow 与最佳实践，能用 AI 显著放大开发效率与产出。
6. 具备较强的自驱力和探索精神，能够在问题不清晰、方案不确定的情况下快速验证和迭代。

## 加分项

1. 海外背景：有海外学习、生活或工作经历，对全球化产品和海外市场有 sense。
2. 独立开发者经验：有自己上线过的 App/Web 产品，渠道包括 App Store、Google Play、Product Hunt、个人项目等；有真实用户和数据更佳。
3. Agent 建设经验：参与过 LangChain、LangGraph、AutoGen、Dify、Coze、Claude Agent SDK 等项目，或自研过 Agent 系统。
4. 产品 sense：能从用户视角思考问题，对优秀产品有审美和判断力，能讲清楚一个产品为什么好。
5. Side Projects、开源贡献、Hackathon 获奖、技术博客等。

## 面试能力画像

这个岗位不是单纯考算法或前端八股，更看重“能不能独立把 AI 产品从想法做出来”。面试中需要重点展示：

1. 端到端交付能力：从需求澄清、方案设计、工程实现、部署上线到数据验证。
2. AI 应用工程能力：LLM 调用、Prompt、RAG、Agent、工具调用、记忆、多轮交互、评测与稳定性。
3. 产品判断力：能识别用户痛点，能用 MVP 快速验证，而不是只堆技术。
4. 快速学习和复现能力：看到新产品、新技术后能拆解、复刻、改造。
5. AI 工具使用能力：能说明自己如何用 AI 辅助编码、调研、测试、重构和产品探索。
6. 协作能力：能与产品、设计、算法沟通，能把模糊问题推进到可执行方案。

## 重点准备题库

### 自我介绍

- 请用 2 分钟介绍你自己，重点讲和这个岗位最相关的经历。
- 你为什么想做 AI 产品孵化方向，而不是纯前端、后端或算法？
- 你认为自己最能匹配这个岗位的 3 个点是什么？

### 项目经历

- 讲一个你从 0 到 1 做过的 AI 或全栈项目。
- 这个项目的用户是谁？解决了什么痛点？
- 你负责哪些部分？技术架构是什么？
- 你遇到过最难的问题是什么？怎么定位和解决？
- 项目有没有上线？有没有真实用户、数据或反馈？
- 如果现在重做一次，你会怎么改？

### AI 应用能力

- 你如何设计一个稳定的 LLM 应用？
- Prompt Engineering 你有哪些实践经验？
- RAG 的基本流程是什么？如何评估检索质量？
- Agent 和普通 LLM Chatbot 的区别是什么？
- 一个 Agent 需要哪些核心模块？
- 如何设计 Agent 的工具调用、记忆和任务规划？
- Multi-Agent 协作适合什么场景？有什么风险？
- 如何降低 hallucination？
- 如何做 LLM 应用的评测？

### 全栈能力

- 如果让你 3 天内做一个 AI 产品 MVP，你会怎么安排？
- React/Next.js 项目中你如何组织页面、组件和状态？
- Node/Python 后端如何设计模型调用接口？
- 如何处理流式输出？
- 如何做登录、权限、数据库和部署？
- 云部署你用过哪些平台？遇到过什么坑？

### 产品与趋势

- 最近你关注的一个海外 AI 产品是什么？为什么值得关注？
- 你如何判断一个 AI 产品是否有价值？
- 看到一个新 AI 产品，你会如何快速复现并做出差异化？
- 你觉得 AI Agent 目前最大的落地瓶颈是什么？
- 你认为小红书适合做哪些 AI 创新功能？

### AI 工具 Workflow

- 你平时如何使用 ChatGPT、Claude、Cursor、Claude Code 或 Codex？
- 哪些任务适合交给 AI，哪些任务不适合？
- 你如何避免 AI 生成错误代码？
- 举一个 AI 显著提升你开发效率的例子。
- 你有没有沉淀自己的 Prompt、工作流或自动化脚本？

## 回答评分标准

每题按 10 分制评分：

- 9-10 分：结构清晰，有真实项目细节，有技术深度和产品判断，能主动讲权衡、数据、复盘。
- 7-8 分：回答完整，能说明做法和原因，但深度、细节或结果证明略弱。
- 5-6 分：知道概念，但偏泛泛而谈，缺少真实实践或关键细节。
- 3-4 分：概念混乱，无法说明实际做法，项目贡献不清晰。
- 1-2 分：明显不熟悉，回答与问题关系弱。

我会额外从 5 个维度给综合评价：

1. 技术深度
2. 产品 sense
3. 项目真实性
4. 表达结构
5. 岗位匹配度

## 推荐回答结构

### 项目题

使用 STAR + 技术拆解：

1. Situation：项目背景和用户痛点。
2. Task：你的目标和负责范围。
3. Action：架构、关键实现、技术选择、难点解决。
4. Result：上线情况、用户反馈、数据结果、复盘改进。

### 产品题

使用 用户-场景-痛点-方案-验证：

1. 用户是谁？
2. 在什么场景下遇到什么问题？
3. 现有方案为什么不够好？
4. AI 能带来什么新能力？
5. 如何用 MVP 验证？

### 技术题

使用 原理-实践-风险-优化：

1. 基本原理是什么？
2. 自己怎么做过？
3. 容易出什么问题？
4. 如何评估和优化？
