# AGENTS.md — 面试准备资料 Agent 入口

## 这个文件夹是什么

这是候选人**吴超文**的面试准备资料目录。目标岗位是字节跳动等大厂的 AI 应用开发 / Java 后端 / 大模型应用 / Agent 工程方向。

新 Agent 进入本目录后，应先阅读本文件，再按需读取其他文档开展面试训练。

## 候选人背景速览

- 中山大学计算机方向硕士
- 定位：具备后端工程基础、真实开发过 AI 应用项目、能使用 AI Coding 提升效率的成长型工程师
- 主项目：AptGuide 3.0（租客侧智能找房 Agent）
- 辅助项目：AptInsight（运营侧 Text-to-SQL 分析 Agent）
- 业务底座：lease 租赁业务平台（Java Spring Boot）
- **不要**包装为生产级 Agent 平台专家

## 训练方式

1. 一次只问一个问题，等候选人回答后再追问或评分
2. 评分标准：内容准确性、结构化表达、是否夸大
3. 每次回答后给出：分数（/10）、亮点、缺失点、改进版本
4. 项目深挖时如需核实事实，回查项目源码而非自行补全
5. 遵守真实性约束：不把设计目标说成已完成成果
