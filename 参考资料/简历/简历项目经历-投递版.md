# 简历项目经历-投递版

## AptGuide 3.0 - 租客端智能找房助手（AI Agent项目 | 独立开发）

· 技术栈：Python、FastAPI、RAG、Milvus、Redis、MySQL、SQLAlchemy、Vue3、Playwright  
· 背景：面向租客找房、规则咨询、预约看房和租约查询等场景，构建可接入租赁主系统的 C 端智能助手。  
· 设计 LLM-first 结构化理解方案，将用户输入解析为任务类型、硬性条件、软偏好、检索查询和风险等级；低置信度或语义矛盾时进入澄清流程，避免关键词误判。  
· 设计找房、规则问答、预约、租约、记忆、人工转接等业务流程，预约创建、取消和偏好记忆写入均通过待确认动作完成，保证写操作可控。  
· 实现 RAG 检索与推荐链路，支持多查询向量召回、业务后端房源校验、五维加权排序、知识库重排和置信度门控。  
· 建设 MySQL + Redis 状态体系，持久化会话、消息、待确认动作、偏好记忆、Trace 和审计事件，并完成阶段性验证，覆盖单元测试、Live RAG 集成测试、前端 E2E 和依赖健康检查。

## AptInsight - 公寓运营智能分析助手（AI后端项目 | 独立开发）

· 技术栈：Python、FastAPI、LangGraph、MySQL、SQLAlchemy、asyncmy、sqlglot、Pydantic、Qwen、Redis  
· 背景：面向公寓后台运营人员的临时数据分析需求，支持用自然语言查询预约、租约、房源、租金、浏览热度等业务数据，并返回表格、图表和运营总结。  
· 使用 LangGraph 编排 Text-to-SQL 链路，拆分意图识别、SQL 生成、安全校验、只读执行、图表构建和答案总结等节点，使流程可观测、可测试。  
· 基于 sqlglot 实现 AST 级 SQL Guard，限制只允许 SELECT 查询，拦截多语句、系统库、危险操作和敏感字段访问，并结合表/字段白名单和只读账号降低数据风险。  
· 整理数据库 Schema、指标口径和 few-shot 示例，约束模型正确使用业务表、枚举值、时间范围和逻辑删除条件，避免编造不存在的字段或支付流水。  
· 构建 Agent Eval Harness，覆盖 40 个业务分析、安全测试和边界拒答场景；最终评测通过率 87.5%，安全用例通过率 100%，核心指标口径通过率 100%。  
· 对多模型链路进行质量与耗时评估，优化提示词、结构化输出和 token 配置，将典型分析请求耗时控制在约 5s。

## SmartLease - 租赁业务管理平台（SpringBoot后端项目 | 独立开发）

· 技术栈：SpringBoot、MyBatis-Plus、MySQL、Redis、JWT、MinIO、Nginx  
· 背景：面向公寓运营的租赁业务场景，抽象房源管理、预约看房、签约、续约、退租等核心流程，提供后台管理接口。  
· 负责核心业务建模与落库设计，覆盖公寓、房间、租约、预约等实体关系，支持多维度条件查询与分页检索。  
· 设计租约状态流转并在接口层做状态约束，保证签约、续约、退租等流程的一致性与数据正确性。  
· 使用 Redis 实现热点房源缓存与 Token 管理，集成 MinIO 完成房源图片上传，并通过 Nginx 反向代理和 Linux 环境完成部署。
