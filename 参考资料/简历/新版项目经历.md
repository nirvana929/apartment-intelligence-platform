# 新版项目经历

## AptGuide 3.0 - 租客端智能找房助手（AI Agent项目 | 独立开发）

· 技术栈：Python、FastAPI、LLM Structured Output、RAG、Milvus、Redis、MySQL、SQLAlchemy、Vue3、Playwright  
· 背景：面向租客找房、租房规则咨询、预约看房和租约查询等场景，构建可接入租赁主系统的 C 端智能助手。  
· 采用 LLM-first 结构化理解方案，将自然语言解析为任务类型、硬性条件、软偏好、检索查询和风险等级；当模型输出低置信度、解析失败或字段矛盾时进入澄清流程，避免关键词兜底带来的误判。  
· 设计 7 类 typed procedures，覆盖找房、规则问答、预约、租约、记忆、人工转接和澄清；预约创建、取消和记忆写入均通过待确认动作完成，保证写操作可控。  
· 实现 RAG 检索链路，支持多查询向量召回、lease 房源校验、五维加权排序、知识库重排、置信度门控和检索诊断，房源推荐结果必须经过业务后端校验后返回。  
· 建设 MySQL + Redis 状态体系，持久化会话、消息、待确认动作、偏好记忆、人工转接、Trace、Procedure Run 和审计事件，并使用 Redis TTL 管理会话与待确认动作热状态。  
· 完成阶段性验证：核心单测 207 项通过，Live RAG 集成 5/5 通过，Playwright 前端 E2E 3 项通过，live 依赖检查覆盖 MySQL、Redis、lease、Milvus、LLM 和 Embedding。

## AptInsight - 公寓运营智能分析助手（AI后端项目 | 独立开发）

· 技术栈：Python、FastAPI、LangGraph、MySQL、SQLAlchemy、asyncmy、sqlglot、Pydantic、Qwen、Redis  
· 背景：面向公寓后台运营人员的临时数据分析需求，支持通过自然语言查询预约、租约、房源、租金、浏览热度等业务数据，并返回 SQL、表格、图表和运营总结。  
· 使用 LangGraph 将 Text-to-SQL 链路拆分为意图识别、SQL 生成、SQL 安全校验、只读执行、图表构建和答案生成等节点，通过状态图管理异常分支和执行结果。  
· 基于 sqlglot 实现 AST 级 SQL Guard，限制只允许 SELECT 查询，拦截多语句、系统库、危险操作和敏感字段访问，并结合表/字段白名单和只读 MySQL 账号降低数据风险。  
· 整理数据库 Schema、指标口径和 few-shot 示例，约束模型正确使用业务表、枚举值、时间范围和逻辑删除条件，避免编造不存在的字段或支付流水。  
· 构建 Agent Eval Harness，固化业务分析、安全测试和边界拒答用例，覆盖 40 个测试场景；最终评测通过率 87.5%，安全用例通过率 100%，核心指标口径通过率 100%。  
· 对多个模型进行链路性能与质量对比，结合提示词约束、结构化输出和 token 参数调优，将典型意图识别、SQL 生成、答案总结链路耗时控制在约 5s。

## SmartLease - 租赁业务管理平台（SpringBoot后端项目 | 独立开发）

· 技术栈：SpringBoot、MyBatis-Plus、MySQL、Redis、JWT、MinIO、Nginx  
· 背景：面向公寓运营的租赁业务场景，抽象房源管理、预约看房、签约、续约、退租等核心流程，提供后台管理接口。  
· 负责核心业务建模与落库设计，覆盖公寓、房间、租约、预约等实体关系，支持多维度条件查询与分页检索。  
· 设计租约状态流转并在接口层做状态约束，保证签约、续约、退租等流程的一致性与数据正确性。  
· 使用 Redis 实现热点房源缓存与 Token 管理，降低重复查询开销并支撑登录态校验。  
· 接口遵循 RESTful 风格并统一返回结构，集成 MinIO 完成图片上传，使用 Nginx 实现静态资源代理与反向代理，并在 Linux 环境完成部署。
