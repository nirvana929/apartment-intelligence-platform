# AptInsight 接口契约与集成方案

## 1. 接口分层

第一阶段只需要 Python Agent API。

第二阶段新增 Spring Boot 包装接口，前端只调用 Spring Boot。

```text
第一阶段：
Postman/测试页 -> Python Agent

第二阶段：
Vue Admin -> Spring Boot -> Python Agent
```

## 2. Python Agent API

### 2.1 健康检查

```http
GET /api/v1/health
```

响应：

```json
{
  "status": "ok",
  "service": "aptinsight-agent",
  "version": "0.1.0",
  "database": "connected",
  "llm": "configured"
}
```

### 2.2 智能分析对话

```http
POST /api/v1/chat
Content-Type: application/json
```

请求：

```json
{
  "sessionId": "session_001",
  "userId": 1,
  "question": "本月各公寓预约量排名",
  "options": {
    "needChart": true,
    "exposeSql": true,
    "maxRows": 200,
    "dryRun": false
  },
  "context": {
    "timezone": "Asia/Shanghai"
  }
}
```

字段说明：

| 字段 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| `sessionId` | string | 否 | 会话 ID，用于多轮追问 |
| `userId` | number | 否 | 后台用户 ID，独立阶段可为空 |
| `question` | string | 是 | 用户问题 |
| `options.needChart` | boolean | 否 | 是否需要图表 |
| `options.exposeSql` | boolean | 否 | 是否返回 SQL |
| `options.maxRows` | number | 否 | 最大返回行数 |
| `options.dryRun` | boolean | 否 | 只生成 SQL，不执行 |
| `context.timezone` | string | 否 | 时区 |

## 3. Agent 错误码

| code | 含义 | 前端提示 |
| --- | --- | --- |
| `UNSUPPORTED_QUESTION` | 问题不支持 | 当前问题不在支持范围内 |
| `SCHEMA_MISSING` | 缺少表或字段 | 当前数据库缺少该分析所需字段 |
| `SQL_GENERATE_FAILED` | SQL 生成失败 | 暂时无法生成查询，请换一种问法 |
| `SQL_GUARD_FAILED` | SQL 安全校验失败 | 查询未通过安全校验 |
| `SQL_EXECUTE_FAILED` | SQL 执行失败 | 查询执行失败 |
| `QUERY_TIMEOUT` | 查询超时 | 查询耗时过长，请缩小范围 |
| `LLM_TIMEOUT` | 模型调用超时 | 智能分析服务响应超时 |
| `INTERNAL_ERROR` | 未知异常 | 智能分析服务暂时不可用 |

## 4. Spring Boot 集成接口

### 4.1 后台聊天接口

新增 Controller：

```text
com.atguigu.lease.web.admin.controller.ai.AptInsightController
```

接口：

```http
POST /admin/ai/chat
Content-Type: application/json
access-token: <jwt>
```

请求：

```json
{
  "sessionId": "session_001",
  "question": "最近 30 天预约趋势",
  "needChart": true
}
```

响应使用现有统一结构：

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "traceId": "ai_20260430_000003",
    "answer": "最近 30 天预约量整体平稳。",
    "sql": "SELECT ...",
    "columns": [],
    "rows": [],
    "chart": {},
    "warnings": []
  }
}
```

### 4.2 Java DTO 建议

请求 DTO：

```java
@Data
public class AptInsightChatRequest {
    private String sessionId;
    private String question;
    private Boolean needChart = true;
    private Boolean exposeSql = true;
    private Integer maxRows = 200;
}
```

响应 DTO：

```java
@Data
public class AptInsightChatResponse {
    private String traceId;
    private String sessionId;
    private String intent;
    private String answer;
    private String summary;
    private String sql;
    private List<AptInsightColumn> columns;
    private List<Map<String, Object>> rows;
    private AptInsightChart chart;
    private List<String> warnings;
    private List<String> suggestedQuestions;
    private AptInsightExecution execution;
}
```

列定义：

```java
@Data
public class AptInsightColumn {
    private String key;
    private String title;
    private String type;
}
```

图表定义：

```java
@Data
public class AptInsightChart {
    private String type;
    private Map<String, Object> option;
}
```

### 4.3 Spring Boot 职责

Spring Boot 负责：

1. 接收前端请求。
2. 复用当前登录鉴权。
3. 获取当前后台用户 ID。
4. 调用 Python Agent。
5. 处理超时和异常。
6. 封装 `Result.ok(data)`。
7. 可选：保存查询日志。

Spring Boot 不负责：

1. 自己生成 SQL。
2. 自己调用大模型。
3. 直接暴露数据库给前端。

## 5. 前端集成方案

### 5.1 新增 API 文件

```text
src/api/aptInsight/index.ts
src/api/aptInsight/types.ts
```

`types.ts`：

```ts
export interface AptInsightChatRequest {
  sessionId?: string
  question: string
  needChart?: boolean
  exposeSql?: boolean
  maxRows?: number
}

export interface AptInsightColumn {
  key: string
  title: string
  type: 'string' | 'number' | 'date' | 'datetime' | 'boolean'
}

export interface AptInsightChart {
  type: 'bar' | 'line' | 'pie' | 'table'
  option: Record<string, any>
}

export interface AptInsightExecution {
  durationMs: number
  rowCount: number
  truncated: boolean
}

export interface AptInsightChatResponse {
  traceId: string
  sessionId?: string
  intent: string
  answer: string
  summary?: string
  sql?: string
  columns: AptInsightColumn[]
  rows: Record<string, any>[]
  chart?: AptInsightChart | null
  warnings: string[]
  suggestedQuestions: string[]
  execution: AptInsightExecution
}
```

`index.ts`：

```ts
import http from '@/utils/http'
import type {
  AptInsightChatRequest,
  AptInsightChatResponse,
} from './types'

export function chatWithAptInsight(data: AptInsightChatRequest) {
  return http.post<AptInsightChatResponse>('/admin/ai/chat', data)
}
```

## 7. 超时与降级

建议：

| 层 | 超时 |
| --- | --- |
| 前端请求 | 60 秒 |
| Spring Boot 调 Agent | 45 秒 |
| Agent 调 LLM | 30 秒 |
| Agent 查 MySQL | 10 秒 |

降级策略：

1. SQL 已生成但总结失败：返回表格和 SQL，提示总结生成失败。
2. 图表生成失败：返回表格，提示图表生成失败。
3. SQL 执行为空：返回空表和“暂无数据”。
4. LLM 失败：返回服务不可用。

## 8. 查询日志表建议

第二阶段可新增：

```sql
CREATE TABLE ai_query_log (
  id BIGINT NOT NULL AUTO_INCREMENT,
  trace_id VARCHAR(64) NOT NULL,
  session_id VARCHAR(64) DEFAULT NULL,
  user_id BIGINT DEFAULT NULL,
  question VARCHAR(500) NOT NULL,
  intent VARCHAR(64) DEFAULT NULL,
  generated_sql TEXT,
  status VARCHAR(32) NOT NULL,
  error_message VARCHAR(1000) DEFAULT NULL,
  duration_ms INT DEFAULT NULL,
  row_count INT DEFAULT NULL,
  create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_trace_id (trace_id),
  KEY idx_user_time (user_id, create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AptInsight 查询日志';
```

日志表只记录 SQL 和摘要，不建议保存完整 rows，避免数据膨胀和隐私风险。
